## 🔧 Comment Ajouter des Traductions

1. Ajouter les clés de traduction dans `src/i18n/translations.js` (section `fr` et `en`)
2. Importer `useTranslation` dans la page : `import { useTranslation } from '../hooks/useTranslation'`
3. Utiliser le hook : `const { t } = useTranslation()`
4. Remplacer les textes en dur par : `t('clé.de.traduction')`
